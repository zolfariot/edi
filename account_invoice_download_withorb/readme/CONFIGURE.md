First, you need to create a Withorb API key. For that, log in to your
[Withorb Dashboard](https://app.withorb.com/), go to *Settings \> API
Keys* and create a new API key with invoice read permissions. Write down
the API key in a safe place.

In Odoo, go to the menu *Invoicing \> Configuration \> Import Vendor
Bills \> Download Bills* and create a new entry. Select *Withorb* as
*Backend* and set the Withorb API Key.
